Licenças

Cada licença é um código fixo que não expira. Dê uma para cada PC: a pessoa digita o código no agente (ou no ClickerAgent.exe) uma única vez e ele conecta para sempre, sem pareamento. Desative para bloquear temporariamente sem perder o código (reative quando quiser, sem precisar mexer no PC), ou remova para apagar de vez.

Botões de alerta

Dispara o mesmo som de sempre (bipe/som do sistema) em todos os PCs ativos.

Mensagens

Para situações diferentes do alerta - use um som diferente (ou um áudio próprio) para não confundir com o alerta normal.
